# GB Highload Course

Учебный проект, развивающий одно приложение от простого React + NestJS API до
контейнеризации и отказоустойчивого кеша.

| Каталог | Этап |
|---|---|
| `gb-demo-app-2` | API новостей, React-интерфейс и валидация |
| `gb-demo-app-4` | Production-сборка и Docker |
| `gb-demo-app-6` | Промежуточная копия этапа 4 |
| `gb-demo-app-7` | Первые эксперименты с Redis/Memcached |
| `gb-demo-app-8` | Актуальная версия: Redis master/replica + Sentinel |

Продолжать разработку следует в [`gb-demo-app-8`](./gb-demo-app-8/README.md).
